# FreshTrack

FreshTrack is a native iOS food expiry and pantry management application designed to help users keep track of stored groceries and reduce avoidable household food waste.

## Project Overview

Users can record food items, assign storage locations, monitor expiry dates, and identify food that needs attention. FreshTrack will also support receipt scanning to reduce manual data entry.

## Technology

- Swift
- SwiftUI
- Core Data
- MVVM
- Use Case Layer
- Repository Pattern
- WidgetKit
- Notification Content Extension

## Architecture

FreshTrack follows:

View → ViewModel → Use Case → Repository → Core Data

## Planned Features

- Add and manage food items
- Fridge, freezer and pantry storage locations
- Expiring-soon tracking
- Receipt scanning and item import
- Home Screen widgets
- Expiry notifications
